# HoloSuite Core 1.2.1

The **Releases** tab in **What's New** now features the first public release of **HoloSuite Loot**, with a link to download it. Loot lets players collect items from defeated NPCs and gives GMs control over loot rules, dice-based quantities, and range.

The feed also includes recent entries for **HoloSuite Terminal 1.4.1** and **Galaxy Map 2.0.1**.
