# HoloSuite Core 1.3.1

**What’s New → Updates** now includes Galactic Records 1.1.0, Pulse Scanner 2.1.1, and CyberCall 2.0.2. Core shows the latest CyberCall news even when an older CyberCall installation registers its own entry.

Cards in **Updates** and **Releases** now use their module’s launcher icon. Cards without a launcher button keep their existing icons.
