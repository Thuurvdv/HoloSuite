# HoloSuite Core 1.3.0

Give the HoloSuite launcher a look that fits your world. GMs can change the device name, logo, and icons, and rename app tiles. Open **Settings → Open HoloSuite Branding** in the launcher to try it. Branding is experimental.

**HoloSuite Buddy** now has its own card under **What's New → Releases**, with the Buddy icon and a short description of the module.
