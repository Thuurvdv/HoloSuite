## Galaxy Map 2.3.0

- Add a 0–100% prominence bar for each faction. GMs can set separate values for the galaxy and each system.
- Add a 0–100% reputation bar for each faction's standing toward the party across the map.
- Use **Configure Settings → Galaxy Map** to choose which tabs show named ratings, percentage bars, both, or neither. Labels are on and percentage bars are off by default in new worlds. Hiding a display preserves its saved ratings.

Requires HoloSuite Core. Supports Foundry VTT v12–v14.
