## Security Cameras 2.0.2

- In Foundry v14, choose a scene level for each Live Canvas camera. The feed shows that level's background, tiles, and tokens while the GM views another level or scene.
- Automatic uses the scene's starting level when possible and follows the linked region when it belongs to a different level.
- Pan to Region switches to the camera's level before centering on the linked region.

Requires HoloSuite Core. Supports Foundry VTT v12–v14.
