# Website fonts

Downloaded on 2026-09-15 from Google Fonts. These WOFF2 files are served by
this website; visitors do not make font requests to Google.

- Barlow: regular (400), semibold (600), bold (700), extra bold (800), black (900).
  Copyright 2017 The Barlow Project Authors (https://github.com/jpt/barlow).
  License: Barlow-OFL.txt.
- Oxanium: variable weight 400–800.
  Copyright 2019 The Oxanium Project Authors (https://github.com/sevmeyer/oxanium).
  License: Oxanium-OFL.txt.

Both fonts use the SIL Open Font License 1.1. Keep the license and copyright
notices with redistributed font files.

The Latin subsets cover the English website text and common Western European
characters. The CSS fallback fonts handle characters outside those subsets.
Browsers load only the weights used on a page; font-display: swap keeps text
visible while fonts load.
