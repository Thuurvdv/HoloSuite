Privacy & Cookies

Last updated: 5 August 2026

This website uses privacy-focused, aggregate audience measurement from GoatCounter. It does not use cookies, browser storage, advertising trackers, or persistent visitor identifiers. That is why you are not shown a cookie consent banner.

Who operates this website

Mage Tower Studios operates this website. For privacy questions or requests, email Magetowerfoundry@gmail.com.

Hosting and connection data

This is a static website hosted by GitHub Pages. When you request a page, the hosting service necessarily receives connection information such as your IP address, the requested URL, and technical request data. GitHub states that it logs and stores visitors’ IP addresses for security purposes, whether or not a visitor is signed in.

This processing supports the legitimate interests of securely delivering and protecting the website (Article 6(1)(f) GDPR, where the GDPR applies). GitHub provides details about its processing, retention, international transfers, and privacy contacts in the GitHub Pages documentation and GitHub Privacy Statement.

Cookies and similar technologies

Mage Tower Studios and the analytics integration do not set or read cookies, local storage, session storage, cache identifiers, or other persistent identifiers in your browser. The website does not use advertising technology, cross-site tracking, profiling, or automated decision-making. If that changes, this notice will be updated and any technology that legally requires prior consent will remain disabled until that consent is given.

Aggregate audience measurement

Mage Tower Studios uses GoatCounter to understand how often pages are visited and, in aggregate, which pages, referrers, countries, browsers, operating systems, languages, and screen-size groups are most common. The purpose is to evaluate and improve the website. The legal basis is the legitimate interest in measuring the quality and effectiveness of the website (Article 6(1)(f) GDPR, where the GDPR applies).

GoatCounter stores results in separate aggregate tables and does not store IP addresses, full user-agent headers, or tracking IDs. To avoid counting repeated requests as separate visitors, the site name, IP address, and user-agent are held only in server memory for up to eight hours and mapped to a random value; the source information is not written to its database. Individual pageview storage is not enabled for this site.

GoatCounter is operated from Ireland, with data hosted by Hetzner in Finland and Germany. It states that analytics information is not shared with third parties. Read the GoatCounter privacy policy and GDPR explanation.

Links to other websites

This website contains ordinary links to services such as GitHub and Patreon. No content from those services is embedded here. Their own privacy and cookie practices apply only after you choose to follow a link and visit them.
