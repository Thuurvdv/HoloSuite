About me

The person behind Mage Tower Studios

Hey! I'm Thuur, the developer behind Mage Tower Studios.

I've been a software developer for about nine years. I finished my Bachelor studies for Applied Computer Science in 2017 (Belgium) and have worked professionally as a developer ever since, with a focus on frontend technologies.

HoloSuite originally came about because I run a D&D 5e campaign set in a futuristic sci-fi setting. Turning a fantasy-focused system into something that feels sci-fi required a lot of tools and utilities that weren't readily available for D&D (hacking for example). For 2 years, I made small macros and scripts for my own campaign, but they were difficult to maintain and often didn't work the way I wanted them to. It was also hard to justify spending a huge amount of time polishing something that was only being used by me and five other dudes.

While I was between campaigns, I figured I could use that free time to start building these tools properly: treating them like actual software projects instead of tiny personal scripts. That also meant I could release them for other GMs and players around the world, which gave me a lot more motivation to keep improving them. Every module I create starts with the same basic idea: it's something I want to use in my own games. I also love flashy interfaces, so a lot of my attention goes into visuals, animation, and making everything feel like it belongs in a sci-fi setting.

I've been having a blast building these modules, and I hope you enjoy using them as much as I enjoy making them.

AI policy

  • + Searching & fixing bugs
  • + Generate boilerplate code
  • + Css
  • + Discussing and reviewing complex features on a technical level
  • + Code cleanup while adding comments to the code
  • + Proof of concepts
  • - Generating images or sounds
  • - Creating advertisement posts
  • - Translations/Labels
  • - 'Vibe coding'
  • - Creating documentation
  • - Module & feature ideas
  • - Full feature development

Any code that the AI generates or edits gets reviewed, tested & tweaked (if necessary) by me before I push it to my repositories. I understand all the code and am able to further develop HoloSuite without issue if AI suddenly would vanish.
