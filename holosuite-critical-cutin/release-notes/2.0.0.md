# HoloSuite Critical Cut-In 2.0.0

- Redesigned UI
- The cut-in editor has a scrollable animation row, drag-to-reorder character lists, and a simpler portrait preview. Player tabs use the first character's portrait. The GM can use the rolling token's artwork.
- There are 15 animations to choose from.
- Set up criticals for rolls like `2d6`, with separate thresholds for success and failure.
- Turn on the bundled success and failure sounds separately. Both start off by default. Local Impact Shake adds a brief shake when a cut-in lands.
- Use **Glory Roll** to put a roll in front of the whole table. Choose who rolls, enter a formula, and set a target if you want. Chat shows each dice term's subtotal. Dice So Nice dice get smaller for larger pools.

Requires **HoloSuite Core**. Works on **Foundry V12–V14**. Dice So Nice is optional.
