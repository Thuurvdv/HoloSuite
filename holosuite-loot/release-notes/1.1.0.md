# HoloSuite Loot 1.1.0

First public release for Foundry VTT. Requires HoloSuite Core and supports D&D5e and Starfinder Second Edition.

- Players can right-click a lootable NPC, inspect items, and collect a stack or use **Loot All**. Successful pickups deplete the placed NPC’s inventory.
- GMs can set lootability and inventory rules per corpse, NPC actor, or shared item source. The refresh button syncs a corpse with its current inventory while preserving pending pickups.
- Dice formulas roll when players collect inventory items. A single grenade configured with `2d6+2` awards the rolled quantity and shows the roll in the player’s chat.
- Loot range defaults to 15 ft and can be adjusted or disabled in Module Settings. Automatic defeat detection, the character selector, and public loot chat are configurable.
- Holo, Neutral, and Fantasy themes include animated SVG corners and matching scrollbars. The opening animation respects reduced-motion preferences.

**Install** by placing the `holosuite-loot` folder from the ZIP in Foundry’s `Data/modules` directory, or by using the release manifest URL once published. Enable HoloSuite Core and HoloSuite Loot in your world.

**Compatibility** targets Foundry V12–V14. The release build was tested live with Foundry 14.369 and D&D5e 5.3.3.
