# HoloSuite Loot 1.3.0

- Adds native loot adapters for Dragonbane, Warhammer Fantasy Roleplay 4e, Star Wars FFG, Call of Cthulhu 7e, and Pathfinder 2e. The adapters filter out character features such as skills and talents and use each system’s item stack quantities.
- Adds automatic defeat detection for eligible NPCs in the new adapters. Star Wars FFG recognizes its Defeated status and adversaries above their wound threshold.
- Transfers native Dragonbane coins, Star Wars FFG credits, and Pathfinder 2e coin stacks. Warhammer adds looted coins to the existing stack of the same denomination.
- Fixes a Star Wars FFG loot listing error caused by numeric item rarity.

Requires **HoloSuite Core** and targets **Foundry V13–V14**. The published Star Wars FFG system supports Foundry V13.
