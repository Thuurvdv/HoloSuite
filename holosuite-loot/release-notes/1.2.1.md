# HoloSuite Loot 1.2.1

- Adds SWADE currency to player loot panels and the GM's **Inventory loot rules**. Players collect the NPC's native currency balance, and existing loot snapshots pick it up automatically.
- GMs can allow, hide, or set a custom currency quantity per corpse or NPC actor. Fixed amounts and dice rolls are capped by the available balance.

Requires **HoloSuite Core** and targets Foundry V13–V14.
