# HoloSuite Loot 1.4.0

- Adds **Keep linked actor** to the GM's Loot panel and **Keep linked actor by default** to world settings. When enabled for an already linked token, looting depletes the world actor's inventory and keeps the token linked. Other tokens linked to that actor share the remaining inventory.
- Preserves the existing unlink-on-loot behavior by default. The new option does not link unlinked tokens or relink tokens that were previously unlinked. Saved token preferences override the world default.
- Protects linked-actor transfers against competing pickups from different tokens and resumes interrupted transfers against their original source actor.
- Fixes competing token menus opening alongside Loot on repeated player right-clicks, including document-level pointer handlers such as DAS Core's. Loot handles the complete right-click gesture on lootable NPCs; GM controls and clicks on other tokens remain available.
- Adds native loot support for **Mothership (MoSh 0.6.1)** on Foundry V13–V14, including physical gear, final-wound detection, and numeric or formatted credit balances on NPCs using the character sheet.
- Adds native loot support for **Pathfinder 1e** on Foundry V13, including physical items, carried coins, lethal-HP detection, and unidentified item descriptions. Dying NPCs are not automatically treated as dead.

Requires **HoloSuite Core**. Targets **Foundry V13–V14**; individual game systems may support fewer Foundry versions.

After updating, reload connected GM and player clients so they use the same Loot build.
