## CyberCall 2.0.0

### New

- Redesigned commlink phone and transmission console, with cyan controls and stronger portrait interference as the signal drops.
- GM access to players' personal and assigned contacts, including editing and portrait browsing.
- Configurable phone number formats with digits, letters, and fixed prefixes.
- Custom device emblems, with optional support for HoloSuite Core Branding. Works with Core versions that do not have Branding yet.
- A notification sound library with GM uploads and player selection, using the same editor as ringtones.

### Fixes

- Messages from different NPCs to the same player stay in separate conversations. Selecting an Actor links it immediately.
- GM NPC conversations show the contacted player's portrait and identify the NPC used for replies.
- Fullscreen previews show the full portrait and message. Contact picture controls no longer cause horizontal scrolling.
- Foundry 12 message rows keep portraits and names aligned left, without an unwanted horizontal scrollbar.
- Window controls sit inside the phone and console; duplicate call labels and unused resize grips have been removed.
- The player launcher no longer shows a links count. This change is contained in CyberCall.

### History

Call history now keeps the newest **100 call events per world**. Older call events are permanently removed when a GM is connected. Text messages and ordinary Foundry chat are preserved.

Supports Foundry VTT 12–14. Requires HoloSuite Core.
